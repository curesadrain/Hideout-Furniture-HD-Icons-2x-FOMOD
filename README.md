# Hideout Furniture - 2x HD Icons Framework

[![Release](https://img.shields.io/github/v/release/curesadrain/Hideout-Furniture-HD-Icons-2x-FOMOD?style=for-the-badge)](https://github.com/curesadrain/Hideout-Furniture-HD-Icons-2x-FOMOD/releases)
[![Platform](https://img.shields.io/badge/Platform-S.T.A.L.K.E.R.%20Anomaly%20%7C%20G.A.M.M.A.-blue?style=for-the-badge)](https://github.com/curesadrain/Hideout-Furniture-HD-Icons-2x-FOMOD)

Modular **FOMOD** installer delivering crisp **2x HD inventory & placement icons** for the **Hideout Furniture** mod family in S.T.A.L.K.E.R. Anomaly and G.A.M.M.A.

---

## English

### Description

**Hideout Furniture - 2x HD Icons Framework** upgrades all placeable item, crafting, and inventory icons to clean, high-resolution 2x textures. Designed specifically for modular setups, the FOMOD installer lets you choose exactly which Hideout Furniture addons you have active.

### Features

- **Full 2x HD Resolution:** Replaces blurry 1x icon sheets with crisp 2x HD textures for items and placeable furniture.
- **Modular FOMOD Installer:** Step-by-step selection for the Core mod and optional addons.
- **Supported Addons:**
  - `00_Core`: Base Hideout Furniture placeable devices and weapon displays.
  - `01_Expansion`: Hideout Furniture Expansion (Maid & HarukaSai) item icons and props.
  - `02_Even_More_Furniture`: Even More Hideout Furnitures (facelessez) decor, doors, and walls.
  - `03_Gadgets`: Gadgets for Hideout Furniture (DoktorDauerfeuer) lamps, heater, radio, etc.
  - `04_Hideout_Cat`: Hideout Cat (DoktorDauerfeuer) placeable cat companion icon.
- **Pure DLTX & XML Integration:** Clean override system that preserves compatibility with all other mods.

### Requirements

- [S.T.A.L.K.E.R. Anomaly](https://www.moddb.com/mods/stalker-anomaly) (1.5.1 / 1.5.2) or [G.A.M.M.A.](https://discord.gg/stalker-gamma)
- [DLTX](https://github.com/RAX-Anomaly/DLTX)
- [Hideout Furniture](https://www.moddb.com/mods/stalker-anomaly/addons/hideout-furniture) (Core) and any desired addons

### Installation

1. Download `Hideout_Furniture_HD_Icons_2x_FOMOD.zip` from [Releases](https://github.com/curesadrain/Hideout-Furniture-HD-Icons-2x-FOMOD/releases).
2. Install via **Mod Organizer 2** (*Install a new mod from an archive*).
3. In the FOMOD installer window, check the addons currently present in your load order.
4. Place this mod **below** all Hideout Furniture mods in your MO2 left panel.
5. Enable the mod.

## Русский

### Описание

**Hideout Furniture - 2x HD Icons Framework** — графический аддон с модульным **FOMOD**-инсталлятором, заменяющий все иконки мебели, предметов и элементов интерьера из линейки модов **Hideout Furniture** на чёткие текстуры разрешения 2x HD.

### Особенности

- **Двойное разрешение (2x HD):** Качественные переработанные 2x текстурные атласы вместо стандартных низкополигональных и размытых иконок.
- **Модульный FOMOD-инсталлятор:** Гибкая настройка при установке — выбирайте только те модули, которые установлены в вашей сборке.
- **Поддерживаемые компоненты:**
  - `00_Core`: Базовый Hideout Furniture (стенды для оружия, верстаки, приборы).
  - `01_Expansion`: Hideout Furniture Expansion (Maid & HarukaSai) — пропсы и предметы.
  - `02_Even_More_Furniture`: Even More Hideout Furnitures (facelessez) — декор, двери, стены.
  - `03_Gadgets`: Гаджеты Hideout Furniture (DoktorDauerfeuer) — лампы, обогреватель, радио.
  - `04_Hideout_Cat`: Hideout Cat (DoktorDauerfeuer) — размещаемый кот.
- **Модульность DLTX и XML:** Чистое подключение через модульные конфиги без риска конфликтов.

### Требования

- [S.T.A.L.K.E.R. Anomaly](https://www.moddb.com/mods/stalker-anomaly) (1.5.1 / 1.5.2) или G.A.M.M.A.
- [DLTX](https://github.com/RAX-Anomaly/DLTX)
- Оригинальный мод Hideout Furniture и необходимые аддоны

### Установка

1. Скачайте архив `Hideout_Furniture_HD_Icons_2x_FOMOD.zip` со страницы [Releases](https://github.com/curesadrain/Hideout-Furniture-HD-Icons-2x-FOMOD/releases).
2. Установите через **Mod Organizer 2** (*Установить новый мод из архива*).
3. В окне установщика FOMOD отметьте установленные в вашей сборке аддоны.
4. Поместите мод **ниже** модов Hideout Furniture в левом списке MO2.
5. Активируйте мод.
